# 实验9：CNN 手写数字识别实验（MNIST）

## 一、实验目的
1. 基于 MNIST 数据集搭建并训练卷积神经网络（CNN），完成手写数字识别任务。
2. 对比不同优化器（SGD、SGD+Momentum、Adam）对模型性能的影响。
3. 探究不同学习率对训练曲线、收敛性及最终准确率的影响。
4. 通过卷积核与特征图可视化，理解 CNN 特征提取机制。
5. 分析错误样本与混淆矩阵，总结模型混淆类别、错误原因及改进方案。

## 二、实验环境
- 编程语言：Python
- 深度学习框架：PyTorch
- 主要库：torchvision、matplotlib、seaborn、scikit-learn、numpy
- 数据集：MNIST 手写数字数据集

---

## 三、实验内容
1. **模型搭建**
   构建包含两层卷积、两层池化、两层全连接层的 CNN 模型。

2. **任务1：基础训练**
   使用 Adam 优化器、学习率 0.001 训练模型，输出测试集准确率。

3. **任务2：优化器对比**
   对比 SGD、SGD+Momentum、Adam 在相同学习率下的收敛速度与准确率。

4. **任务3：学习率对比**
   固定 Adam 优化器，对比学习率 `0.1 / 0.01 / 0.001` 的训练效果。

5. **任务4：卷积核可视化**
   展示第一层卷积核权重，观察边缘、方向、纹理特征。

6. **任务5：特征图可视化**
   观察不同特征图对数字笔画、边缘、轮廓的响应区域。

7. **任务6：错误样本分析**
   收集并展示模型误分类样本，分析易混淆数字。

8. **任务7：混淆矩阵分析**
   统计各类别分类情况，定位最易混淆类别及错误分布。

## 五、结论
1. **优化器性能**：Adam 收敛最快、准确率最高，SGD+Momentum 优于普通 SGD。
2. **学习率影响**：学习率 0.1 模型不收敛；0.01 可收敛但波动较大；0.001 为最优。
3. **特征提取**：卷积核自动学习边缘、方向特征，特征图高亮数字笔画与轮廓区域。
4. **混淆情况**：数字 5 与 3、4 与 9、2 与 4 等形态相似类别最易混淆。
5. **错误原因**：手写不规范、变形、模糊，模型对细微特征区分不足。

## 六、改进方案
- **数据**：使用数据增强、难例挖掘提升鲁棒性。
- **模型**：增加网络容量、加入 BN 层、使用残差结构。
- **训练**：采用加权损失、学习率衰减、早停策略、AdamW 优化器。
