## 实验环境
1. Python 3.8+
2. 依赖库：
   - opencv-python
   - numpy
   - glob、os（Python内置库）

安装依赖命令：
```bash
pip install opencv-python numpy
```

## 代码功能说明（lab12.py）
1. **棋盘参数定义**：设置9×6内角点纸质棋盘，方格边长20mm，生成标定板三维世界坐标；
2. **图像读取**：批量读取`testimagess4`文件夹下所有jpg标定图片；
3. **棋盘角点检测**：调用`cv2.findChessboardCorners`识别黑白棋盘内角点；
4. **亚像素精度优化**：使用`cv2.cornerSubPix`细化角点坐标，提升定位精度；
5. **相机标定求解**：通过`cv2.calibrateCamera`计算相机内参矩阵K、5项畸变系数、每张图像旋转平移外参；
6. **结果输出打印**：输出全局RMS重投影误差、内参、畸变系数、图像分辨率；
7. **畸变校正**：选取第一张原图生成畸变映射表，完成去畸变处理；
8. **文件保存**：将角点可视化图、原始测试图、校正后图像统一保存至`experiment12_output`文件夹。

## 运行方式
1. 将标定原图放入`testimagess4`文件夹；
2. 终端进入代码所在目录，执行：
```bash
python lab12.py
```
3. 运行完成后所有可视化结果自动生成至`experiment12_output`目录；
4. 终端控制台打印完整标定数值结果。

## 实验关键结果摘要
1. 图像分辨率：1440 × 810
2. 全局重投影RMS误差：0.9180 像素（小于1像素，标定精度合格）
3. 标定素材：纸质打印棋盘，微信手机相机拍摄，共15张不同姿态图像，无角点检测失败样本
4. 校正效果：原始图像四角存在径向拉伸畸变，校正后棋盘方格横竖线条平直，畸变消除效果明显
