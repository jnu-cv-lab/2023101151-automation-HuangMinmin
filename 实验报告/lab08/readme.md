# 实验八 基于卷积神经网络的图像分类实验

## 一、实验目的
本实验基于 PyTorch 搭建卷积神经网络（CNN），完成 MNIST 手写数字识别任务，并通过进阶实验，探究网络结构、优化器算法及数据集复杂度对模型分类性能与泛化能力的影响，加深对卷积神经网络工作原理与训练优化过程的理解。

## 二、实验环境
- Python 版本：3.x
- PyTorch 版本：2.12.0+cu130
- 计算设备：CPU
- 依赖库：torch, torchvision, numpy, matplotlib

## 三、实验内容与步骤
1.  **基础任务：MNIST 手写数字识别**
    - 加载并预处理 MNIST 数据集，划分训练集、验证集与测试集。
    - 搭建基础 CNN 模型，包含 2 层卷积层与 2 层全连接层。
    - 训练 10 个 epoch，记录训练损失与准确率变化，在测试集上评估模型性能。

2.  **进阶任务1：网络结构改进**
    - 对基础模型进行多维度优化：增加卷积层、提升卷积核数量、扩大全连接层神经元规模，并引入 Dropout 正则化。
    - 对比改进前后模型在测试集上的准确率变化，分析结构优化的效果。

3.  **进阶任务2：优化器对比实验**
    - 在相同基础 CNN 模型上，对比 SGD（带动量）与 Adam 两种优化器的训练效果。
    - 记录不同优化器在对应学习率下的测试准确率，分析优化器对训练收敛与最终性能的影响。

4.  **进阶任务3：MNIST 与 CIFAR-10 数据集对比**
    - 对比两个数据集的图像类型、类别数、测试准确率与识别难度。
    - 分析 CIFAR-10 比 MNIST 更难的原因，理解数据复杂度对模型性能的影响。

## 四、实验结果
### 1. 基础任务结果
- 基础模型测试准确率：**99.04%**
- 训练过程中，训练损失持续下降，训练准确率稳步提升，验证准确率稳定在 98.8%~99.0% 之间，模型表现出良好的收敛性与轻微过拟合现象。

### 2. 进阶任务1结果
- 改进模型测试准确率：**99.17%**
- 准确率较基础模型小幅提升，证明加深加宽网络并引入 Dropout 正则化，可有效增强模型特征提取能力与泛化性能。

### 3. 进阶任务2结果
| Optimizer | Learning Rate | Test Accuracy |
|-----------|---------------|---------------|
| SGD       | 0.01          | 98.92%        |
| Adam      | 0.001         | 98.75%        |
- 在本次简单分类任务中，带动量的 SGD 优化器表现略优于 Adam，说明优化器效果需结合任务特性与超参数综合评估。

### 4. 进阶任务3结果
| 数据集 | 图像类型 | 类别数 | 测试准确率 | 难度 |
|--------|----------|--------|------------|------|
| MNIST  | 灰度手写数字 | 10 | 99.04% | 低 |
| CIFAR-10 | 彩色自然图像 | 10 | 62.41% | 高 |
- CIFAR-10 因图像背景复杂、类间差异细微，识别难度远高于 MNIST，相同模型下准确率显著降低。

## 六、实验结论
本次实验成功完成了所有任务，验证了卷积神经网络在图像分类任务中的有效性。结果表明：
1.  合理的网络结构优化（加深、加宽、加入正则化）可以提升模型的精度与泛化能力。
2.  不存在绝对最优的优化器，其性能表现与任务复杂度、数据特性及超参数设置密切相关。
3.  数据集复杂度是决定模型性能上限的关键因素，真实场景图像分类对模型特征提取能力的要求远高于人工规整数据集。
