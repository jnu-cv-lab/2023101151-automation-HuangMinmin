## 三、功能实现说明（对应作业5项要求）
### 1. 实现Sinusoidal Position Encoding
按照Transformer原始论文三角函数公式实现正弦位置编码，根据输入最大序列长度`max_len`与特征维度`d_model`，偶数维采用`sin`、奇数维采用`cos`，基于指数衰减频率批量生成所有位置的位置编码矩阵，每行向量对应序列单个位置的位置信息。

### 2. 实现二维向量旋转
编写二维向量旋转函数，基于标准旋转矩阵公式完成坐标变换，输入二维向量与旋转弧度，输出旋转后的新向量，该函数是高维RoPE实现的基础原子操作。

### 3. 实现高维RoPE
将高维特征向量按照两个维度为一组进行拆分，每组二维向量根据当前位置`pos`计算专属旋转角度，调用二维旋转函数逐组完成几何旋转，最终拼接得到经过RoPE位置嵌入后的完整向量。

### 4. E+pos与RoPE输入方式对比实验
随机生成一组词嵌入矩阵，分别使用两种位置嵌入方案：
- E+pos：原始词向量与同维度正弦PE逐元素直接相加；
- RoPE：对每个位置的词向量做分组旋转变换，不进行数值加法；
控制台同步输出原始词嵌入、E+pos结果、RoPE结果，直观对比两种编码修改向量的差异：pos=0时RoPE向量与原向量完全一致，E+pos受加法影响数值发生偏移；pos≥1时E+pos依靠加法改变向量幅值，RoPE依靠旋转改变向量方向。

### 5. 数值实验验证RoPE相对位置特性
固定一组测试Q、K向量，选取**绝对位置不同、相对间距相同**的两组配对`(pos=2,pos=5)`与`(pos=0,pos=3)`（间距均为3），分别对Q、K施加对应位置的RoPE旋转并计算点积，最终两组点积数值完全相等，差值趋近于0，从数值层面验证RoPE点积仅由相对距离决定。

## 四、原理分析：RoPE相较于E+pos的优势
1. Transformer自注意力为并行运算架构，模型本身无法感知词语先后顺序，因此必须引入位置编码补充时序信息。传统正弦PE通过固定三角函数生成位置向量，E+pos直接相加的注入方式会把词的语义内容与位置信息融合在同一组数值中，信息无法解耦，造成内容与位置混杂。
2. RoPE摒弃数值相加的融合思路，采用几何旋转嵌入位置信息，并且仅对注意力计算所需的Q、K向量做旋转变换，保留Value向量原始特征。依托三角函数数学性质，旋转后的Q、K做内积运算时，点积结果只依赖两个Token的相对位置差值，使得Attention Score中的相对位置关联依托旋转结构自然生成，不需要模型从海量数据中额外学习相对语序，相比E+pos天然适配自然语言的相对位置规律，同时具备优秀的超长文本外推能力。

## 六、实验结论
1. E+pos是加法式绝对位置编码，修改向量整体数值，内容与位置信息耦合，无法天然建模相对位置；
2. RoPE是旋转变换式编码，向量模长不变、仅改变方向，位置信息融入夹角，点积天然绑定相对距离，在建模语序、长文本泛化上优于传统E+pos方案。
