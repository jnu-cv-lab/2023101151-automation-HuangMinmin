# 实验七  手写数字图像分类实验 README
## 一、实验简介
本实验基于 `scikit-learn` 内置手写数字数据集，采用多种传统机器学习算法完成 0~9 手写数字图像分类任务。实验涵盖数据加载、特征转换、数据集划分、多模型训练、准确率评估、混淆矩阵绘制、错误样本分析完整流程，对比不同传统分类器在小尺寸图像分类上的性能差异与适用场景。

## 二、实验环境
- Python 3.x
- 依赖库：`numpy`、`matplotlib`、`scikit-learn`

## 三、数据集介绍
- 数据集名称：sklearn digits 手写数字数据集
- 图像尺寸：8 × 8 像素灰度图像
- 总样本数量：1797 张
- 类别数量：10 类（数字 0～9）
- 特征表示方式：将 8×8 二维像素矩阵按行展平，转换为 64 维一维特征向量，作为机器学习模型输入。

## 四、使用的机器学习算法
实验共采用六种传统机器学习分类器：
1. **KNN（K近邻）**
2. **Naive Bayes（朴素贝叶斯）**
3. **Logistic Regression（逻辑回归）**
4. **SVM（支持向量机）**
5. **Decision Tree（决策树）**
6. **Random Forest（随机森林）**

每种算法均统一完成：模型初始化、训练集训练、测试集预测、分类准确率统计。

## 五、实验流程
1. 加载手写数字数据集，读取图像与标签信息；
2. 将二维 8×8 图像展平为 64 维特征向量；
3. 划分训练集与测试集，用于模型训练和性能评估；
4. 依次初始化六种机器学习模型，分别进行训练与测试预测；
5. 计算并输出各模型测试集分类准确率；
6. 选择表现较好的 **SVM** 模型，绘制混淆矩阵、可视化分类错误样本；
7. 对比各模型准确率，分析模型差异与错误分类原因。

## 六、实验结果概述
1. 不同模型分类准确率存在明显差异：**KNN、SVM、Logistic Regression、Random Forest** 准确率较高，分类效果优异；**Naive Bayes** 与 **Decision Tree** 准确率相对偏低。
2. KNN 在规整小像素图像上精度最优，但预测阶段计算开销较大；朴素贝叶斯结构简单、运算快，但受特征独立假设限制，适配图像像素相关性较差；逻辑回归适合线性分类场景，非线性拟合能力有限；SVM 泛化能力强，适合高维小样本数据；单棵决策树可解释性强但易过拟合；随机森林通过集成学习抑制过拟合，结果更稳定。
3. 对 SVM 错误样本分析发现：分类误差主要集中在外形相似的数字，如 3 与 8、5 与 6、7 与 9 等；原因是 8×8 低分辨率图像细节有限，仅依靠原始像素特征难以区分相似轮廓。

## 七、核心结论
1. 传统机器学习无法直接输入二维图像，必须将图像展平为一维特征向量才可进行模型训练与预测。
2. 原始像素作为特征实现简单，但存在明显局限：丢失空间结构信息，对图像平移、旋转、缩放敏感，无法提取高层语义特征，相似样本区分能力不足。
3. 集成类模型（随机森林）相比单棵决策树过拟合程度更低、泛化性与稳定性更好；基于间隔与距离的模型（SVM、KNN）更适配小尺寸手写数字分类任务。
